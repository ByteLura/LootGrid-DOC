The Grid Model

InventoryGrid is the heart of LootGrid Pro — a pure model class with no UI types in it. Everything the player does is a validated operation on this model; the views only show its state.

Footprints and placement

  • Every placed item occupies an exact rectangle of cells: its definition's Width × Height, swapped when rotated.
  • Placement is checked three ways: in bounds, no overlap, and — at the container level — the weight limit.
  • TryPlaceAt places at an exact cell; TryAdd first-fits (and tops up matching stacks first); Move relocates a placed item, ignoring its own cells but respecting everything else; Remove frees the cells immediately.
  • First-fit is deterministic: the same grid state always produces the same layout.

Rotation

A definition's CanRotate decides whether its footprint may swap. Rotation applies mid-drag (the ghost resizes to the rotated footprint), to a click-selected item in place, and in the model API (Grid.Rotate). A non-rotatable item refuses everywhere, consistently.

Stacking and splitting

  • Stackable definitions merge up to their MaxStack. Adds top up the first matching stack before opening new ones and report how many units could not be placed — never a silent loss.
  • SplitStack divides a stack into exact counts; a full-count split is refused (that is a move, not a split). Shift-drag in the UI carries half the stack, rounded up, through the same code path.
  • AutoStack merges every mergeable pile in the grid and returns how many merges happened.

Sorting

Three modes — BySize, ByRarity, ByName. Sorting repacks through a scratch grid: the new layout is adopted only if every stack fits, so a sort can never lose or duplicate an item. If a repack cannot fit, the sort returns false and the original layout stands.
