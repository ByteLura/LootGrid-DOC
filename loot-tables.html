Loot Tables

A LootTable is a ScriptableObject of weighted entries:

FieldMeaning
ItemThe definition that can arrive.
WeightRelative roll weight (the demo uses 3 / 3 / 2 / 1 / 1).
MinCount / MaxCountThe stack size range on a hit (rolled inclusively).

Rolling

var rolled = table.Generate(rng, rolls);   // List<ItemStack>
  • Generation is seeded: pass a System.Random you control and the same seed produces the same loot — replays, tests and daily seeds behave identically. (The demo passes its own System.Random; the design deliberately uses it instead of a global random source.)
  • Each roll picks one entry by weight and a count in its range. Rolled stacks respect MaxStack — a roll never produces an illegal stack.
  • Arriving is the container's job: the demo's Loot the Wreck feeds each rolled stack through the chest's TryAdd and reports on the status line exactly what arrived — and, when the chest cannot take something, how many units had no room.

What tables cannot do

A table rolls which defined items arrive. It does not invent items, stats or affixes — there is no procedural item generation in v1, by design.
