Quick Start

The demo (about two minutes)

  1. Open Tools > ByteLura > LootGrid Pro. The welcome block is at the top, with the version line and five quick actions.
  2. Click Import the Loot Yard Sample, then Build the Demo Scene. The builder authors ten item definitions, a database, a loot table, two containers, a loadout and the screen into Assets/LootGrid Pro Demo and opens the scene.
  3. Press Play. Drag the Iron Sword from the Wreck Chest into the Backpack — it is 1×3, so press R while dragging to rotate it into the space. Then press Loot the Wreck.

Deleting Assets/LootGrid Pro Demo removes the demo completely.

Verify your install

Verify Install (welcome block, or Tools > ByteLura > LootGrid Pro > Verify Install) checks the assemblies, exercises the model in memory (place, rotate, stack, sort, save, restore) and confirms the sample and documentation are present — one plain-language line per check. It creates nothing in your project and is safe to re-run.

Your own game in three steps

  1. Define items (workshop window or Assets > Create > ByteLura > LootGrid). Give every item a stable Id — it is the save key. Collect definitions into one Item Database and validate it.
  2. Place containers. One InventoryContainer per container: size, weight limit, unique Container Id, starter items.
  3. Build the screen where you open your inventory:
var screen = InventoryScreenView.Build(
    canvasTransform, backpack, chest, loadout.Equipment, theme);

The second container, the equipment set and the theme are all optional; pass null and the screen builds without them (a null theme uses the shipped defaults).
