Troubleshooting

First step for almost everything

Run Verify Install (workshop welcome block, or Tools > ByteLura > LootGrid Pro > Verify Install). Its lines check the assemblies, exercise the model in memory, and confirm the sample and documentation are present. If a line fails, its wording is the diagnosis.

Common questions

The demo scene has no Loot / Take All / Sort buttons.

The scene was built before the sample was imported, so the demo driver is not in it (the builder logs exactly this). Click Import the Loot Yard Sample, then Build the Demo Scene again.

An item will not rotate.

Its definition has CanRotate off, or the rotated footprint does not fit where it stands / where the ghost is pointing. The status line tells you which.

A drop says "Too heavy".

The destination container is at its weight limit. Raise the limit on the InventoryContainer (0 = unlimited) or move something out — the readout in the panel header is the live total.

Restore reported warnings.

By design: a warning names an item Id missing from the database, or an entry that no longer fits. Everything not named restored normally. Keep definition Ids stable once saves exist.

Two containers share a Container Id.

Saves match by Container Id; duplicates are a validation warning in the Quick Start sense — give each container a unique Id.

Removing the demo / the doll.

Delete Assets/LootGrid Pro Demo — nothing else was touched. For the doll: remove the equipment module files listed in The Equipment Doll; the grid core never references them.

Still stuck: see Support.
