Honest Limits — What v1 Is Not

Version 1.0.0, printed rather than buried:

  • Not a crafting system. No recipes, no combining, no disassembly. Inventory and loot only.
  • Not a shop or an economy. No vendors, no currency, no buy/sell mechanics. An item's Base Value is inert data for your own systems — nothing in this package spends it, sells with it, or totals it.
  • Not an item-stats system. Definitions carry identity, footprint, rarity, weight and value. What a sword does when swung is your game code.
  • Not a networking solution. Inventories are local state. The save data classes are the integration surface if your netcode needs to move inventory state around.
  • Not Addressables-aware. Icons are plain Sprites on the item definitions, loaded with the definitions themselves.
  • Not keyboard/gamepad navigable. The grid is driven by pointer (mouse or touch). Click-to-move exists so precise dragging is never the only way to move an item, but there is no focus navigation in v1.
  • Not TextMeshPro. All screen text is uGUI Text, so the package has zero dependencies and works on a bare Unity install.
  • Not a procedural item generator. Loot tables roll which defined items arrive, in what counts. They do not invent stats or affixes.
  • Verified scope. Tested on Unity 6000.5.4f1 and Unity 2022.3.22f1, Windows Editor. No other platform or device verification is claimed.
